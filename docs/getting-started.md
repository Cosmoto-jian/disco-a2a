# Disco 上手指南：从 Discord 机器人到第一场群聊

Disco 本身不用 Discord 也能用。接上 Discord 后，每个 agent 会在你的服务器里有自己的频道，你在手机上也能指挥它们、批准权限请求。

整个流程大约 10 分钟：

1. 准备一个 Discord 服务器
2. 在 Discord 开发者后台新建机器人，拿到 Token
3. 把 Token 填进 Disco，邀请机器人进服务器
4. 添加 agent，开始私聊和群聊

---

## 1. 准备一个 Discord 服务器

已经有自己的服务器可以跳过。

1. 打开 Discord，点左侧服务器列表最下面的 **＋**
2. 选「亲自创建」→「仅供我和我的朋友使用」
3. 起个名字，比如 `disco-lab`

> 你必须是这个服务器的所有者或管理员，才能把机器人拉进来。

---

## 2. 新建机器人，拿到 Token

### 2.1 创建应用

1. 打开 <https://discord.com/developers/applications>，用同一个 Discord 账号登录
2. 点右上角 **New Application**
3. 名字随意，比如 `DiscoHub`，勾选同意条款，点 **Create**

### 2.2 生成 Token

1. 左侧菜单点 **Bot**
2. 在 **Token** 一栏点 **Reset Token**，确认（可能要输入 Discord 密码或两步验证码）
3. 点 **Copy** 复制这串 Token

> ⚠️ Token 相当于机器人的密码，**只显示一次**。不要发到群里、不要提交到 Git。丢了就再点一次 Reset Token，旧的会立即失效。

### 2.3 打开「消息内容」权限（必须）

还是在 **Bot** 页面，往下滚到 **Privileged Gateway Intents**：

- ✅ **MESSAGE CONTENT INTENT** —— 打开

点页面底部的 **Save Changes**。

> 不开这一项，机器人能上线，但读不到你在频道里发的文字，agent 不会回复。另外两项（Presence、Server Members）Disco 用不到，保持关闭即可。

建议顺手把 **Public Bot** 关掉，这样别人无法把你的机器人拉进他们的服务器。

---

## 3. 在 Disco 里填入 Token

1. 打开 Disco，点左侧栏最下面的 **设置**（齿轮图标）
2. 在 **Discord** 一栏，把刚才复制的 Token 粘贴进输入框，点 **保存**
3. 看到「token 有效，已保存」，状态点变绿显示「在线」就成功了

Token 只保存在本机的 macOS 钥匙串 / Windows 凭据管理器里，不会写进任何文件。

### 3.1 邀请机器人进服务器

保存 Token 后，Discord 设置下方会出现 **「重新授权 Bot（补齐管理频道等权限）」** 按钮：

1. 点它，浏览器会打开 Discord 授权页
2. 「添加到服务器」里选你的服务器，点 **继续** → **授权**
3. 回到 Disco，服务器下拉框里就能看到它了

> 这个链接已经带好了 Disco 需要的全部权限（建频道、发消息、Webhook、按钮交互等），不用自己去开发者后台勾选。以后升级 Disco 遇到权限不够的提示，再点一次这个按钮即可。

### 3.2 选主服务器，同步频道

1. 在「主服务器」下拉框选你的服务器
2. Disco 会在该服务器里建一个 **Disco Agents** 分类，给每个 agent 建一个频道
3. 之后新增了 agent，点 **同步频道** 补建

### 3.3 允许其他人指挥（可选）

默认只有**机器人的所有者**（也就是你）在 Discord 里说话 agent 才会响应。要让朋友也能用：

1. Discord 里打开「用户设置 → 高级 → 开发者模式」
2. 右键朋友的头像 → **复制用户 ID**
3. 粘贴到 Disco 设置里「其他可指挥 agent 的 Discord 用户 ID」，多个用英文逗号分隔，点 **保存**

---

## 4. Disco 的简单使用

左侧栏五个入口：**聊天 · 群聊 · Agent · 待处理 · 设置**。

### 4.1 添加 agent

点 **Agent** → 添加 Agent。Disco 会自动扫描这台电脑上装好的 agent：

| 类型 | 说明 |
|---|---|
| 本机已安装的 | Claude Code、Codex、Gemini CLI、Qwen Code、Goose、OpenCode 等，点 **导入** 一步完成；点整行可以改名字、工作目录、conda 环境、开多个实例 |
| 其他本地 agent | 任何支持 ACP 协议的程序，填启动命令，如 `/path/to/agent --acp` |
| 朋友的邀请码 | 粘贴朋友发来的 `disco1:` 开头的邀请码 |
| 远程 A2A agent | 填 URL，可选鉴权头 |

导入时可以挑一个**会动的几何形象**和配色；以后点头像或菜单里的「更换形象…」随时换。

### 4.2 私聊

导入后会直接打开和它的对话。像聊天一样发消息即可：

- agent 回复是流式显示的，工作中头像会动得更快
- 说「记住 …」，它会把这条记到自己的长期记忆里，以后每次新会话都会带上
- 同一时间 Discord 里它的频道会同步出现这段对话，在手机上回复也一样

### 4.3 群聊

点 **群聊** → 新建群聊，起名、勾选成员，点 **创建群聊**。在群里：

| 写法 | 效果 |
|---|---|
| `@coder 帮我看下这个报错` | 只让 coder 回答 |
| `@all 各自说说思路` | 所有成员一起回答 |
| `/team 做一个登录页` | 团队模式：组长拆分任务、成员并行干活，最后汇总 |

群里的 agent 也会互相 @，接力把事情做完。右上角抽屉里有本群的 **待办** 和共享 **文档**，agent 可以自己读写。

### 4.4 待处理

agent 要执行敏感操作（改文件、跑命令）或者有问题要问你时，会出现在 **待处理**，左侧栏有红点提示。

- 在 Disco 里点批准 / 拒绝 / 回答
- 或者在 Discord 频道里点机器人消息下面的按钮

两边任意一边先处理就算数，另一边会自动更新。

### 4.5 把 agent 共享给朋友

两台电脑都装好 Tailscale，并且在同一个 Tailscale 网络里：

1. 在本地 agent 菜单点 **共享给朋友…**
2. 填对方名字，选权限（「只聊天」或「需要时问我」），设每天消息上限
3. 点 **生成邀请码**，`disco1:` 开头的码会自动复制
4. 发给对方，对方在「添加 Agent → 朋友的邀请码」里粘贴

已共享的列表里可以随时 **撤销**。设置里的「Tailscale 访问规则」还能限定只有名单内的设备能用，以及设置免打扰时段。

### 4.6 多人多 agent 群聊（各带各的 Bot）

Discord 的群频道就是 Disco 的群：能在这个频道发言的人都能和群里的 agent 对话。

**把你的 agent 带进朋友的群：**

1. 设置 → Discord → **复制邀请链接（给朋友）**，发给朋友
2. 朋友打开链接，把你的 Bot 加进他的服务器（只有服务器管理员能加）
3. 你在 Disco 里 **新建群聊**，Discord 一栏选他的频道，勾上要带去的 agent

每台 Disco 只回答 @ 到自己 agent 的消息；agent 在你自己的电脑上跑，需要批准的操作只问你。

**群规：**

- `@agent`：它立刻回答，可以同时 @ 几个
- 只 @ 人：agent 不插话
- 谁都没 @：只有你一个人的群由组长回答；多人群里 agent 不插话
- agent 的回复都以 @对方 开头；它 @ 另一个 agent 就是交接
- `@agent /命令`：运行它自己的命令（清空、换模型等只有主人能用）
- `/stop` 停止所有回复，`/help` 看群规，`/team 任务` 分工协作（群主）

谁能进群由 Discord 频道权限决定，建议把群频道设成私密频道。

### 4.7 记忆开关

每个对话顶部有「记忆」开关，默认开启。关闭后这个对话既不读取也不保存长期记忆，重启后保持。

## 常见问题

**机器人在线，但频道里发消息没反应**
多半是没开 MESSAGE CONTENT INTENT（见 2.3）。在 agent 自己的频道里，发消息的人还必须是机器人所有者或在允许名单里（见 3.3）；在多人群里，要 @ 到 agent 它才回答。

**提示 token 无效**
Token 复制不完整，或者之后又点过 Reset Token。回开发者后台重新生成一个再粘贴。

**服务器下拉框是空的 / 提示 Bot 还没加入任何服务器**
还没完成 3.1，点「重新授权 Bot」把它邀请进来。

**新加的 agent 在 Discord 里没有频道**
在设置里点 **同步频道**。

**Disco 更新**
App 会自动检查更新，macOS 和 Windows 同步发布。
